# Isaac Sim Notes

Use this folder for Isaac Sim scripts, USD scene notes, and extension setup for
the multi-UAV scene-generation workflow.

## Workflow

1. Open Isaac Sim.
2. Load or create the Haeundae Marine City geospatial scene.
3. Attach Cesium/3D Tiles context.
4. Spawn three UAV camera rigs.
5. Synchronize image capture and pose export.
6. Save exported data under `outputs/`.
