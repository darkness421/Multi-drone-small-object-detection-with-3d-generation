# Report Archive

Last organized: `2026-06-21`

This folder holds superseded report bundles that may still be useful for audit
or comparison, but should not be treated as the current implementation report.

- `server_fresh_baselines/`: older fresh-baseline-only dashboards and tables.
- `progress_visual_assets_20260530/`: archived concept figures kept only as redraw/reference material.
- `live_cleanup_20260621/`: old live dashboards, stale pending figures, and earlier supplementary live snapshots.
- `reports_cleanup_20260621/`: old queue report bundles, stale top-level status
  files, and outdated supplementary detector snapshots.

Use `../live/`, `../final_detector_tables/`, and `../detector_rankings/` for the
current detector evidence. Archive files are historical unless a current README
explicitly points back to them.
