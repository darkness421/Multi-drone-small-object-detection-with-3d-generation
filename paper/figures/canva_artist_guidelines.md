# Canva Figure Guidelines for ACCV 2026

Use this main-repository guide as the source for the Canva artist:

`paper/figures/figure_and_canva_guide.md`

The Overleaf-linked paper repository should stay submission-clean and should not
store Canva briefs or editable SVG templates. When a figure is ready, export the
final paper asset from Canva and copy only the final `.pdf` and, if needed,
`.png` into the Overleaf `figures/` folder.

- Start drawing Fig. 1 pipeline, Fig. 2 YOLO+proposed module, and Fig. 3 evidence graph layouts now; replace placeholder panels with real experiment assets later.

- Keep editable Canva/SVG/source files in the main project or artist workspace, not in Overleaf.
