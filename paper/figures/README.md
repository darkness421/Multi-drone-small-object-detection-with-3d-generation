# Paper Figure Drafts

This folder stores small, editable figure sources that are safe to keep in Git.
Large simulator captures, raw render dumps, model weights, and dataset images
should stay outside Git and be copied into the final paper package only after
selection.

Current draft figures:

| File | Purpose |
| --- | --- |
| `fig01_overall_framework.svg` | Overall CoM3D-ACE pipeline and contribution map |
| `fig02_detector_module.svg` | Proposed detector module and ablation structure |
| `fig03_isaac_multiuav_benchmark.svg` | Isaac Sim MarineCity multi-UAV benchmark setup |
| `fig04_3d_weather_reconstruction.svg` | Weather restoration and 3D reconstruction comparison |
| `fig05_llm_reobservation_policy.svg` | LLM reasoner and active re-observation policy |

Recommended paper flow:

1. Use Figure 1 in the introduction/method overview.
2. Use Figure 2 in the detector/proposed module section.
3. Use Figure 3 in the benchmark dataset section.
4. Use Figure 4 in the 3D reconstruction/weather robustness section.
5. Use Figure 5 in the LLM reasoner/re-observation section.
