\section{Conclusion}
\label{sec:conclusion}

We presented CoM3D-ACE, an ambiguity-centric cooperative multi-UAV perception
framework that connects UAV small-object detection, cross-view 3D evidence, and
graph-grounded reasoning. The 2D frontend, SAFR-YOLO, improves the normalized
three-seed VisDrone detector comparison while using fewer parameters than the
strongest stock YOLO baseline in our table. Beyond the detector, the MarineCity
real-Cesium protocol demonstrates that multi-UAV captures, detector
EvidenceTokens, cross-view evidence graphs, and neural-3D runner-family smoke
metrics can be integrated into a single evidence-completion pipeline.

The current system results are intentionally reported conservatively. We claim
the 2D detector result as the completed quantitative contribution and report
MarineCity as real-Cesium system/protocol validation rather than as a finished
large-scale 3D reconstruction benchmark. Future work will extend the MarineCity
capture set, add longer optimized 3D validation, and import external-provider
AeroGraph responses before promoting the reasoner to a final benchmark claim.
