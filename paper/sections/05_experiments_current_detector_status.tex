\subsection{Current Detector Search Status}
\label{sec:current_detector_search_status}

This section summarizes the detector experiments completed so far. The detector architecture is still being searched, and the final proposed detector may change after the compact-transfer experiments finish. Therefore, the current results are used to guide the next design step rather than to freeze the final method.

\paragraph{Comparison baselines.}
Among the collected plain YOLO-family baselines, YOLOv11l is currently the strongest baseline on the VisDrone validation protocol, with AP 0.3777 and AP50 0.5981. YOLOv12l and YOLOv8l are close, but remain slightly lower in AP. We keep these stock YOLO scale rows separate from prior-art detector models proposed by related papers. RT-DETR-L is reported as a generic non-YOLO baseline. CSFPR-RTDETR and LEAF-YOLO are related-work prior models evaluated at 640-pixel input resolution from repository-available assets; these rows are useful same-dataset sanity checks, but they should not be mixed directly with the 1280-pixel YOLO/proposed rows until the final comparison protocol is normalized.

\paragraph{Current best candidate.}
The current selected trade-off candidate is \textbf{P2P4-SelfAttnFR-s123}. It keeps the high-resolution P2/P3/P4 detection path and adds the SelfAttnFR refinement with TinySpatialFReLU. Compared with YOLOv11l, it improves AP from 0.3777 to 0.3825 and AP50 from 0.5981 to 0.6061, while reducing the parameter count from 25.32M to 20.82M. This is a useful trade-off result because it improves accuracy while using about 17.8\% fewer parameters.

This result is still treated as a candidate rather than a frozen final detector. After the current queue finishes, the final model should be confirmed with seeds 42, 123, and 2026, and the paper should report mean, standard deviation, and significance tests against the strongest YOLO-family and runnable related-work comparison rows.

\paragraph{Ablation trend.}
The module-search results indicate that adding stride-4 evidence is helpful for small-object detection, but the final detector should control parameter growth. Earlier P2-CBAM-FR and DCT-FR candidates achieved slightly higher single-seed AP, but exceeded the YOLOv11l parameter budget. The P2P4-SelfAttnFR line is therefore more suitable for the current paper story because it keeps the detector compact while preserving high-resolution evidence. Follow-up ablations should test SelfAttnFR, TinySpatialFReLU, NMS variants, and frequency modules separately before the final repeated-seed run.

\paragraph{Next detector experiments.}
The active queue keeps the detector search separate from the later 3D reconstruction and reasoning experiments. GPU0 should continue compact proposed-detector follow-up around P2P4-SelfAttnFR, while GPU1 is used for reviewer-facing comparison coverage, including plain YOLO scale sweeps and runnable related-work prior models. Once the detector table is stable, the system-level reconstruction and reasoning components can be evaluated independently.
