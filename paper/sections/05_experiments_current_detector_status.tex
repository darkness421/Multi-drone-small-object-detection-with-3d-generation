\subsection{Detector Results and Reporting Scope}
\label{sec:detector_results_scope}

This section should report only paper-eligible detector evidence. To keep the
main paper self-contained and concise, the main detector table includes completed
VisDrone2019-DET validation runs under the normalized 1280-pixel protocol. Rows
from single-seed architecture search, active training queues, 640-pixel
repository sanity checks, and dry-run scripts are excluded from the main table
and should be reported in the supplementary material only when they clarify the
design process.

\paragraph{Main-table rule.}
The main detector comparison should contain the selected detector candidate and
the strongest normalized YOLO-family baselines. Smaller YOLO scale sweeps,
related-work models that currently have only 640-pixel evaluations, NMS
sensitivity, Grad-CAM/heat-map analysis, and module-search trails
belong in the supplementary material. This prevents protocol-mismatched rows
from weakening the main claim.

\paragraph{Selected detector candidate.}
The current selected detector candidate is \textbf{SAFR-YOLO}. It keeps a
high-resolution P2/P3/P4 detection path and adds SelfAttnFR refinement with
TinySpatialFReLU; the current implementation label is P2P4-SelfAttnFR. Compared
with YOLOv11l under the same three-seed protocol, it
improves AP from 0.3777 to 0.3822 and AP50 from 0.5981 to 0.6052 while reducing
the parameter count from 25.32M to 20.82M. This is the clean main-paper claim:
better AP/AP50 and fewer parameters than the strongest normalized stock YOLO
baseline. The trade-off cost is higher GFLOPs, so the paper should not claim a
speed or compute reduction unless later profiling supports it.

The paired-seed test against YOLOv11l gives AP $p=0.0126$ and AP50 $p=0.0223$
with seeds 42, 123, and 2026. Precision, recall, and F1 should remain secondary
supporting metrics because their paired significance is weaker at the current
sample size.

\paragraph{Ablation reporting.}
The main paper should include only the compact final ablation once the planned
rows finish: YOLOv11l, P2P4 head only, P2P4+TinySpatialFReLU, P2P4+SelfAttn,
full SAFR-YOLO, and a small NMS sensitivity row or figure. Single-seed
search candidates such as DCT, wavelet, CBAM, and other module probes should be
kept in the supplementary material as design evidence unless they become part of
the selected detector.

\paragraph{Excluded rows.}
CSFPR-RTDETR and LEAF-YOLO are currently useful related-work checks, but their
available rows are 640-pixel evaluations. They should not appear in the main
detector comparison until a normalized 1280-pixel protocol or clearly separated
supplementary table is ready. Likewise, YOLO nano/small/medium scale sweeps are
important for reviewer coverage, but they are better placed in the supplementary
material to preserve the main paper page budget.
