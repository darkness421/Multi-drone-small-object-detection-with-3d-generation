\subsection{Supplementary MarineCity System Details}
\label{sec:supp_marinecity_system_details}

This supplementary section records the supporting MarineCity artifacts that are
summarized in the main paper. The main text keeps the compact system-smoke and
neural-3D metric tables; this section provides the capture source,
evidence-graph details, and current reasoner-validation status.

\paragraph{Capture-source analysis.}
Table~\ref{tab:supp_marinecity_real_capture_benchmark} verifies that the
MarineCity scene used for the system smoke test is a real-Cesium capture source
with synchronized UAV viewpoints, camera metadata, RGB frames, and depth-like
exports. These records support the main qualitative figure by showing that the
detector and 3D graph operate on saved geospatial captures rather than on a
procedural stand-in scene.

\paragraph{Evidence-graph analysis.}
Table~\ref{tab:supp_marinecity_crossview_evidence_graph} gives the intermediate
3D evidence representation used by the reasoner. Multi-view support edges
indicate observations that agree across UAVs, while conflict and missing-view
edges identify object hypotheses that require re-observation or cautious
verification. The table is therefore interpreted as an ambiguity-routing
artifact, not as a metric 3D localization benchmark.

\paragraph{Reasoner-validation analysis.}
Table~\ref{tab:supp_aerograph_reasoner_validation_slot} separates the completed
rule-based system check from external-provider LLM/VLM validation. The current
rule-based verifier is useful for confirming schema, graph consistency, and
allowed-action logic. It is not used as evidence that a final external reasoner
has been benchmarked; that claim requires the provider responses to be imported
and checked under the same prompt schema.

\paragraph{Reporting-split analysis.}
Table~\ref{tab:supp_marinecity_reporting_split} states how the system evidence
is divided between the main paper and supplementary material. The main paper
contains the self-contained claims: detector performance, real-Cesium system
operation, and neural-3D smoke metrics. The supplementary material stores the
larger operational details needed for reproduction and reviewer inspection.
